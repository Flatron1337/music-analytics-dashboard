## 📖 Обзор

**Music Analytics Dashboard** — это комплексная открытая платформа и кроссплатформенное приложение, превращающее вашу медиатеку Яндекс Музыки в интерактивный аналитический центр. 

Сервис анализирует тысячи треков, автоматически классифицирует музыку по 6 кластерам с помощью **Last.fm API** и **Нейросетей (Google Gemini 3.6 Flash / Groq)**, строит интерактивный **граф фитов артистов**, генерирует стильные **карточки Story (9:16)** для социальных сетей и позволяет экспортировать **умные плейлисты** прямо в ваш аккаунт Яндекс Музыки в один клик.

## ✨ Ключевые возможности

### ⚡ Интеллектуальная кластеризация жанров
- **6 целевых кластеров:** Точное разделение на *Heavy & Metal*, *Dubstep & EDM*, *Phonk & Memphis*, *Hip-Hop & Trap*, *Rock & Alternative* и *Other & Electronic*.
- **Многоуровневый анализ:** Встроенная база знаний + сопоставление по ключевым словам + сбор тегов с **Last.fm API**.
- **🧠 AI-помощник (Google Gemini / Groq):** Автоматическая доклассификация редких андерграундных треков и артистов, отсутствующих на Last.fm, с учетом контекста названий композиций и соавторов.
- **SQLite кэширование:** Все найденные жанры и теги сохраняются локально навсегда, обеспечивая мгновенную повторную загрузку.

### 🔄 Потоковая синхронизация (Live SSE Sync)
- **Авторизация в 1 клик:** Подключение через Яндекс OAuth (Device Code flow) с персистентным сохранением сессии.
- **Server-Sent Events (SSE):** Прямая трансляция прогресса сбора и анализа медиатеки из тысяч треков без зависаний с выводом живого статуса и процентов.
- **Чистый старт:** Никаких устаревших локальных файлов по умолчанию — медиатека всегда отображает актуальные лайки пользователя.

### 🕸 Граф связей и карта коллабораций
- **Интерактивная сеть соавторов:** Визуализация музыкальных связей между любимыми исполнителями на физическом движке (NetworkX, PyVis и кастомный Canvas в мобилке).
- **Метрики влияния:** Размер узла отражает количество совместных релизов и вес артиста в медиатеке.
- **Индивидуальная карточка артиста:** Мгновенный просмотр списка всех фитов, треков и основных партнеров по сцене.

### 📸 Персональная Story (9:16) для соцсетей
- **Музыкальный архетип:** Определение вашего типа слушателя (*«Электронный Рейвер»*, *«Повелитель Тяжести»*, *«Фонк Дрифтер»* и др.).
- **Генерация инфографики:** Автоматический расчет хронометража, процента коллабораций, топ-3 артистов и долей жанров.
- **Экспорт в галерею:** Кроссплатформенное скачивание готового PNG-изображения высокого разрешения прямо в папку **«Загрузки»** смартфона или компьютера.

### 🪄 Экспорт «Умных плейлистов» в Яндекс Музыку
- **Готовые смарт-пресеты:**
  - ⚡ *«Жанровые кластеры»* (Чистый Dubstep, Phonk или Metal).
  - 🤝 *«Фитотека»* (Только совместные треки и коллаборации).
  - 💎 *«Скрытые жемчужины»* (Любимые треки малоизвестных или единичных артистов).
  - ⏳ *«Золотая эра»* (Первые 100 треков, добавленные в медиатеку).
- **Умный батчинг:** Обход лимитов Яндекс API при пакетном добавлении сотен треков с валидацией `album_id`.

### 📱 Кроссплатформенный клиент (Flutter)
- **Web / PWA / Android / iOS / Desktop:** Единый реактивный интерфейс в стиле Dark Cyberpunk / Yandex Dark.
- **Плавные графики и микроанимации:** Полноценная визуализация таймлайна, интерактивные срезы жанров на `fl_chart`.

## 🛠 Стек технологий

### Backend & Gateway
- **Язык:** Python `3.10+`
- **Единый шлюз (Unified Proxy):** `aiohttp` (асинхронное проксирование HTTP, WebSocket и SSE потоков)
- **REST API:** `Flask`, `Flask-CORS`
- **Веб-дашборд:** `Streamlit`, `Plotly`, `PyVis`, `NetworkX`
- **Интеграция с API:** `yandex-music` SDK, `Last.fm Audioscrobbler API`
- **Нейросети (AI):** `Google Gemini 3.6 Flash REST API`, `Groq Cloud API (Qwen 3.8 / LLaMA)`
- **База данных:** `SQLite3` (WAL-режим для кэша жанров и исполнителей)
- **Облачный хостинг:** `Render` (автодеплой через `render.yaml`)

### Mobile & Web App (`yndex_mobile`)
- **Фреймворк:** `Flutter 3.x` (Channel stable)
- **Язык:** `Dart 3.x`
- **Сетевой стек:** `http` (с поддержкой потокового чтения Server-Sent Events)
- **Графика и чарты:** `fl_chart`, кастомный `CustomPainter` для графа связей
- **Шрифты и UI:** Google Fonts (`Inter`, `JetBrains Mono`), Material Design 3 Dark Neon
- **Экспорт медиа:** `dart:html` (Web Blob download) / `dart:io` (Android Downloads)

## 🚀 Установка и запуск

### Предварительные требования
- Установленный **Python 3.10+**
- Установленный **Flutter SDK 3.x** (для запуска мобильной/веб-версии)
- Git

---

### 1. Клонирование репозитория
```bash
git clone https://github.com/Flatron1337/music-analytics-dashboard.git
cd music-analytics-dashboard
```

### 2. Запуск Backend и Web-сервера (Python)
```bash
# Создание виртуального окружения
python -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate

# Установка зависимостей
pip install -r requirements.txt

# Запуск единого шлюза (Streamlit + Flask REST API)
python main.py
```
* 🌐 **Единый порт (Шлюз):** `http://localhost:10000`
* 💻 **Streamlit Дашборд:** `http://localhost:8501` (проксируется на `/`)
* 📱 **Flask REST API:** `http://localhost:5001` (проксируется на `/api/`)

---

### 3. Запуск мобильного / веб-клиента (Flutter)
```bash
cd yndex_mobile

# Загрузка пакетов Flutter
flutter pub get

# Проверка линтером и запуск тестов
flutter analyze
flutter test

# Запуск в браузере Chrome
flutter run -d chrome

# Или запуск на подключенном Android устройстве
flutter run -d android
```

## 🏗 Архитектура

Проект построен по модульной архитектуре с микросервисным разделением слоёв:

```text
                           ┌──────────────────────────────┐
                           │   Клиенты: Flutter / Web    │
                           └──────────────┬───────────────┘
                                          │ HTTP / SSE / WS
                                          ▼
                      ┌────────────────────────────────────────┐
                      │    main.py (Aiohttp Unified Router)   │
                      │       Порт 10000 (Внешний шлюз)        │
                      └───────┬────────────────────────┬───────┘
                              │ /                      │ /api/*
                              ▼                        ▼
        ┌──────────────────────────────┐     ┌────────────────────────────────┐
        │     Streamlit Dashboard      │     │      Flask REST API Server     │
        │        (Порт 8501)           │     │          (Порт 5001)           │
        └──────────────┬───────────────┘     └────────┬──────────────┬────────┘
                       │                              │              │
                       ▼                              ▼              ▼
           ┌───────────────────────┐      ┌──────────────┐   ┌───────────────┐
           │ Yandex Music Live API │      │ Last.fm API  │   │ Gemini / Groq │
           │  (OAuth, Likes, Sync) │      │ (Scrobbler)  │   │  AI Assistant │
           └───────────────────────┘      └───────┬──────┘   └───────┬───────┘
                                                  │                  │
                                                  ▼                  ▼
                                        ┌─────────────────────────────────┐
                                        │    SQLite (genre_cache.sqlite)  │
                                        │  Персистентный кэш артистов/тегов│
                                        └─────────────────────────────────┘
```

- **Unified Proxy (`main.py`):** Запускает параллельно Flask и Streamlit, проксирует SSE-потоки без буферизации и маршрутизирует трафик.
- **REST API (`api.py`):** Отвечает за аутентификацию, потоковый синк, выдачу данных для графа, аналитики треков и экспорт плейлистов.
- **Smart Classifier (`genre_classifier.py`):** Гибридная система классификации (Локальные правила ➔ SQLite ➔ Last.fm ➔ AI-нейросеть).

## ⚙️ Конфигурация (Environment Variables)

| Переменная | Описание | Значение по умолчанию |
| :--- | :--- | :--- |
| `PORT` | Порт внешнего единого шлюза | `10000` |
| `PYTHONUNBUFFERED` | Отключение буферизации логов в stdout | `1` |
| `GEMINI_API_KEY` | Ключ Google Gemini 3.6 Flash для AI-классификации | Опционально |
| `GROQ_API_KEY` | Ключ Groq Cloud API (Qwen/LLaMA) для резервного AI | Опционально |
